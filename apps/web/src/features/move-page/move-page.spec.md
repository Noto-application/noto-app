# Spec: Перемещение страницы

**Статус:** Draft
**Автор:** —
**Дата:** 2026-09-11
**Связанные:** issue #55

## Цель

Пользователь может переместить страницу к другому родителю через диалог или
перетаскиванием строки дерева. После перемещения он остаётся на странице, URL
не меняется.

## Вне scope

- Перемещение между проектами.
- Изменение порядка среди соседей через диалог.
- Скрытие пункта для роли `viewer` до появления `currentUserRole` от бэкенда.

## Контракт

- Слайс `features/move-page` отправляет `PATCH /pages/:id` с
  `{ parentId, position }`.
- При переносе через диалог страница добавляется последней среди детей
  выбранного родителя.
- В DnD drop на строку добавляет страницу последней среди её детей; зоны до и
  после строки вставляют страницу в соответствующую позицию среди сиблингов.
- Из кандидатов на нового родителя исключаются сама страница и все её потомки.
- Серверная проверка `400 VALIDATION_ERROR` страхует от рассинхрона.
- После успеха инвалидируется список страниц.

## Поведение

1. Пользователь выбирает «…» → «Переместить», нового родителя в дереве или
   пункт «В корень проекта» и подтверждает перемещение. Страница добавляется
   в конец выбранной группы.
2. Пользователь может перетащить строку дерева на нового родителя, в корень
   проекта или в зону до/после другой строки. Drop на строку добавляет её
   последней среди детей; зоны до/после позволяют изменить порядок в той же
   группе или при переносе в другую группу. Используются та же мутация и та же
   защита от цикла.

## Крайние случаи

| Случай                                        | Ожидание                                  |
| --------------------------------------------- | ----------------------------------------- |
| Новый родитель — сама страница или её потомок | Такая страница не попадает в кандидаты.   |
| Drop на невалидную цель                       | Перемещение блокируется.                  |
| Рассинхрон данных                             | Сервер возвращает `400 VALIDATION_ERROR`. |

## Взаимодействия

- Пункт «Переместить» находится в общем меню «…» строки дерева рядом с
  пунктом «Удалить». Меню собирается в `widgets/sidebar`; feature предоставляет
  диалог перемещения через публичный API и не зависит от удаления.
- Кнопка «+» для создания вложенной страницы появится рядом с меню в #84.
- Для DnD используется `dnd-kit`.

## Открытые вопросы

Нет.

## Проверки

- Тест-первым: чистые функции фильтрации кандидатов и расчёта назначения
  исключают страницу и всех её потомков, определяют нового родителя и позицию.
- Вместе с кодом: RTL smoke для перемещения через диалог.
- DnD автоматически не тестируется; взаимодействие проверяется спайком и
  вручную.

## Этапы ревью

Одна ветка и один PR; каждый этап показывается на ревью до перехода к
следующему.

1. Мутация и пункт меню «Переместить».
2. Диалог выбора нового родителя из дерева, пункт «В корень проекта» и
   фильтрация поддерева.
3. DnD: перетаскивание строки на родителя или в корень с той же мутацией и
   защитой от цикла.

## Зависимости

Бэкенд уже поддерживает `create`, `list`, `get`, `update` с перемещением и
`delete`.
