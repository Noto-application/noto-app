# Frontend: разделение на треки и контракт между ними

Гайд на старт фронтенд-разработки. Три параллельных трека по разным слоям FSD,
чтобы три разработчика не толкались в одних файлах. Задачи — FE-2 / FE-3 / FE-4.

Источник дизайна — Design System из Figma Make (Storybook-ready): токены,
инвентарь компонентов, состояния, редактор.

## Треки

| Трек | Задача | Скоуп | Папки (FSD) |
| ---- | ------ | ----- | ----------- |
| **A · UI-kit** | FE-2 | Токены + базовые компоненты (shadcn) + Storybook | `shared/ui/*`, `shared/config` |
| **B · App shell** | FE-3 | Сайдбар, топбар, layout, роутинг `/app/[pageId]`, дерево проектов | `widgets/sidebar`, `widgets/topbar`, `app/`, `entities/project`, `entities/page` |
| **C · Auth + data** | FE-4 | Экраны login/register/forgot, ts-rest client, Query provider | `features/auth`, `shared/api`, `entities/user`, `app/(public)` |

Разные директории → мёрджи не конфликтуют.

## Порядок и зависимости

Трек A (UI-kit) — фундамент для B и C. Чтобы никто не простаивал:

1. **A стартует первым**, его первый PR минимальный — только токены + первая
   пачка атомов (button, input, checkbox, select, badge, avatar) + поднятый
   Storybook. Этот PR ревьюим в приоритете.
2. B и C идут **параллельно**. Пока нужного атома нет — временный локальный
   компонент **с тем же API, что у shadcn**, потом свап `import`-заменой.
3. Проекты (трек B) упираются в **ACL-ADR** (в работе): дерево рисуем, но
   мутации/права — после ADR. Пока read-only каркас на фикстурах.
4. Auth (трек C) садится на бэк `#3`/`#4`, когда они в `main`.

## Контракт между треками

Чтобы три ветки собрались в одно приложение без разъезда:

1. **FSD-слои строго**: `app → pages → widgets → features → entities → shared`.
   Импорт только «вниз». `packages/shared` (monorepo) ≠ FSD `shared` (уровень
   app) — не путать ([ADR-008](adr/008-fsd-structure.md)).
2. **Границы папок** — как в таблице выше. В чужой слой не лезем; нужна правка
   общего — через PR к владельцу трека.
3. **API компонентов = shadcn.** Трек A держит пропсы shadcn-совместимыми, B/C
   пишут против них. Временные локальные атомы — с тем же интерфейсом.
4. **Токены — единственный источник цвета/отступов.** Хардкод hex/px запрещён,
   только переменные из Design System.
5. **Состояние по матрице [ADR-005](adr/005-state-management.md):** URL —
   навигация и `pageId`/`projectId`; TanStack Query — server state; Zustand —
   только UI (сайдбар, модалки, тема); формы — React Hook Form. `pageId` в URL,
   не в Zustand.
6. **Storybook (трек A) — общая площадка ревью** вёрстки.
7. Ветки — латиницей, PR с ревью, прямой push в `main` запрещён (branch
   protection).

## Что пока не берём (парк)

Вторая-третья волна, каждый пункт тянет бэкенд:

- Редактор на BlockNote — отдельный **спайк** (по процессу: спайк → тесты потом)
- AI-генерация текста (Продолжить / Улучшить / Сократить / саммари)
- Telegram-уведомления, инбокс, календарь
- Комментарии и @упоминания
- Загрузка изображений/файлов (S3)
- OAuth/Google, 2FA
