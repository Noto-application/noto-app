# Спецификации фич

Спецификация (spec) описывает **значимую** фичу до начала разработки: цель,
контракт, поведение, крайние случаи. Нужна, чтобы и разработчики, и AI-агенты
работали в заданных рамках, а не додумывали детали.

## Где живёт spec

**По умолчанию — рядом с кодом** (co-location): `<name>.spec.md` в папке модуля
или FSD-слайса.

```
apps/api/src/auth/auth.spec.md
apps/web/src/features/auth/auth.spec.md
```

Спека рядом с кодом обновляется вместе с ним и попадает в контекст AI-агента,
который работает в этой папке. Централизованная папка спек деградирует в
кладбище устаревших документов — поэтому её не используем как основное место.

**Эта папка (`docs/specs/`)** — только для:

- **реестра** — [`REGISTRY.md`](./REGISTRY.md) со ссылками на все co-located спеки;
- **кросс-модульных спек**, которые не влезают в один модуль (фича через
  `apps/api` + `apps/web` + `packages/shared`, например единый auth-flow);
- **шаблона** — [`_template.md`](./_template.md).

## Когда писать spec

| Масштаб                                           | Процесс                                        |
| ------------------------------------------------- | ---------------------------------------------- |
| Значимая фича (auth, редактор, публикация, поиск) | Spec → тесты → код; spec ревьюят перед стартом |
| Обычный модуль / эндпоинт                         | Тест-первым; spec — пара строк в описании PR   |
| Багфикс, вёрстка, мелочь                          | Тест где осмысленно; spec не нужен             |

Порог субъективный: если по фиче есть неочевидные решения или несколько
взаимодействующих частей — пиши spec.

## Правила

- Spec описывает **поведение и контракт**, а не реализацию. Если spec
  пересказывает код прозой — вы пишете всё дважды.
- Имя co-located файла: `<name>.spec.md` рядом с модулем. Кросс-модульная спека —
  `docs/specs/<область>-<фича>.md`.
- Новую спеку добавляй в [`REGISTRY.md`](./REGISTRY.md).
- Spec — живой документ: меняется вместе с кодом.
- `.spec.md` не подхватывается jest (`testRegex` завязан на `.ts$`), сборкой и
  линтером — можно безопасно держать рядом с кодом.
