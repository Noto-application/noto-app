Одна-две фразы: какую задачу пользователя решает фича и зачем. Без деталей
реализации.

## Вне scope

Что фича **не** делает — чтобы AI и разработчик не расширяли рамки. Явно.

## Контракт

возможности ссылкой на ts-rest контракт в `packages/shared`). Для UI —
пропсы/события, состояния экрана.

ожидаемым результатом. Это будущие тест-кейсы.
