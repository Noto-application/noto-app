# RFC-005: Дополнительные библиотеки

**Статус:** Draft  
**Дата:** 2026-07-14

## Контекст

Ряд фич из ТЗ требует специализированных библиотек. Выбор **не утверждён** — зафиксированы только кандидаты.

## Календарь

**Требование:** работа с календарём, связь с todo и TG-уведомлениями.

| Кандидат | Плюсы | Минусы |
|----------|-------|--------|
| FullCalendar | Зрелый, много фич | Тяжёлый, лицензия для некоторых плагинов |
| @schedule-x/react | Лёгкий, modern | Меньше community |

**Статус:** не утверждено

## Загрузка файлов (image/video)

**Требование:** медиа в редакторе и страницах, хранение в S3.

| Кандидат | Назначение |
|----------|------------|
| react-dropzone | UX drag-and-drop upload |
| S3 presigned URLs | Прямая загрузка с клиента на S3 через API |

**Статус:** не утверждено

## Поиск

**Требование:** поиск + фильтры по страницам и проектам.

| Вариант | Когда |
|---------|-------|
| Server-side (PostgreSQL full-text / Elasticsearch) | Основной поиск, масштаб |
| fuse.js на клиенте | Небольшие workspace, offline-like feel |
| Гибрид | Server search + client highlight |

**Статус:** не утверждено

## Drag-and-drop

**Кандидат:** `@dnd-kit/core` — для блоков редактора и дерева страниц в сайдбаре.

Упомянут в [ADR-006](../adr/006-realtime.md) как планируемый; финальный ADR после spike редактора.

## packages/ui

**Вопрос:** когда выносить shadcn-обёртки в `packages/ui`?

**Предварительно:** не на старте ([ADR-001](../adr/001-monorepo-structure.md)). Выносим когда:

- [ ] UI-компоненты нужны в `apps/blog`
- [ ] Storybook живёт отдельно от `apps/web`
- [ ] >15 shared компонентов дублируются

## Следующие шаги

По мере начала работы над каждой фичей — отдельный мини-ADR или обновление этого RFC.
